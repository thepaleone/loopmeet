# OpenCode Agent Memory

Purpose: pointer file so OpenCode (and other coding agents) find the project's real context without a second copy to keep in sync.

## Source of truth

Read these directly — don't rely on a cached copy in this file:

- `CLAUDE.md` — tech stack per feature, plus a "Manual Additions" section with the real architecture, conventions, gotchas, and commands.
- `AGENTS.md` — same auto-generated tech-stack/recent-changes data as `CLAUDE.md` (both are regenerated by `.specify/scripts/bash/update-agent-context.sh`).
- `.specify/memory/constitution.md` — supersedes all other guidance (code quality, testing, simplicity, modularity gates every plan/PR must satisfy).

This file used to embed full raw snapshots of `CLAUDE.md` and `AGENTS.md`. That was dropped because `update-agent-context.sh` doesn't know this file exists — it only ever updates `CLAUDE.md`/`AGENTS.md` — so any content copied in here would silently go stale the next time either of those files changed. Keep it that way: if you're tempted to paste content into this file instead of linking to it, don't.

## Response and Analysis Depth

- Current mode: deep
- Preferred levels:
  - quick: concise answer and minimal exploration
  - medium: standard engineering pass with focused validation
  - deep: broad codebase exploration, alternatives, tradeoffs, and explicit rationale
- Default for this repository: use deep mode for planning, debugging, architecture, and cross-file changes unless the user requests otherwise.
